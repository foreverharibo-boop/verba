# 베르바

SillyTavern 1.18용 독립 자동번역 확장입니다.

현재 버전: **v0.4.65**

## 업데이트 내역

### v0.4.65

- 프롬프트 프리셋에 **저장 범위** 선택 추가
  - `프롬프트만` / `프롬프트 + 번역 설정`
- `프롬프트만`은 기존처럼 4개 프롬프트 내용 + 각 슬롯 ON/OFF만 저장
- `프롬프트 + 번역 설정`은 추가로 아래 항목을 함께 저장·적용
  - 번역 규칙 우선순위
  - 번역 미세 조정: 관계 온도, 서술 현지화, 대사 현지화
  - 대사 말끝 취향
  - 표현 디테일
  - 한캐의 맛 전체 설정
  - 영캐의 맛 전체 설정
- 연결 프로필, 성능 통계, 이름 고정, 금지어, 개발자 모드/관계 실험실, 백업, 디버그, 캐시·임시 상태는 프리셋에 저장하지 않음
- 기존에 저장된 프리셋은 자동으로 `프롬프트만` 범위로 유지되며 불러와도 현재 번역 설정을 건드리지 않음
- 번역 설정 포함 프리셋은 목록에 `· 설정 포함`으로 표시
- 선택된 프리셋을 저장할 때 현재 저장 범위로 덮어쓸 수 있어 `프롬프트만 ↔ 프롬프트 + 번역 설정` 전환 가능

### v0.4.64

- 프롬프트 프리셋의 `새로 저장` / `복제` 구조를 정리
- `새로 저장`을 **`저장`**으로 변경하고 `복제` 버튼 제거
- 프리셋이 선택되어 있으면 현재 프롬프트 4칸 + ON/OFF 상태로 **해당 프리셋을 덮어쓰기 저장**
- 프리셋을 선택하지 않은 상태에서는 입력한 이름으로 새 프리셋 생성
- 선택된 프리셋의 이름을 수정한 뒤 `저장`하면 이름과 현재 값이 함께 저장되며 즐겨찾기 상태는 유지
- 같은 이름의 다른 프리셋이 있을 때는 중복 저장 방지

### v0.4.60

- 개발자 모드 `관계 번역 실험실`에 **호칭 사용 빈도** 추가
  - `최소 / 자연스럽게 / 자주`
  - 호칭 고정 강도와 별개로 실제 대사에서 설정 호칭을 얼마나 자주 꺼낼지 조절
  - 모든 단계에서 `you` 기계 치환 금지, 자연스러운 생략 및 원문 애칭·명시 호칭 우선 유지
- **존댓말·반말 급변 감시** 추가
  - 추가 API 호출 없이 최종 TARGET CHARACTER 번역 대사만 로컬 검사
  - 한 구간 안의 강한 존댓말/반말 혼재, 연속 캐릭터 대사 사이의 강한 존반말 전환을 보수적으로 감지
  - USER/타인 말투가 둘 다 같은 값으로 지정된 경우 해당 설정과 명백히 반대되는 종결도 감지
  - 감지 시 경고와 최근 감시 상태만 표시하며 자동 수정하지 않음
  - 의도적인 비꼼·연출 가능성이 있으므로 `오류`가 아닌 `의심`으로만 표시

### v0.4.59

- 개발자 모드 `관계 번역 실험실`에 **청자별 말투 분리** 추가
- `USER에게` / `타인에게`를 각각 `미설정 / 반말 / 존댓말`로 지정 가능
- 미설정은 기존 말투 거리감과 사용자 프롬프트를 그대로 따름
- 반말/존댓말 설정은 TARGET CHARACTER가 해당 청자에게 말하는 것이 확실한 경우에만 적용
- 청자가 애매하거나 USER와 타인이 섞인 복수 청자, 불명확한 오프스크린 청자, 인용 대사는 임의 추측하지 않고 기존 규칙으로 fallback
- 청자별 설정은 해당 청자에 대해서만 기본 `말투 거리감`보다 우선하며, 의미·감정·캐릭터성·애칭·관계 사실은 바꾸지 않음
- UI 명칭은 `청자별 말투 분리`로 사용 (`압존법`과는 다른 기능)

### v0.4.58

- 개발자 모드 `관계 번역 실험실`에 **호칭 고정 강도** 옵션 추가
- `자연스럽게`: 장면 분위기/한국어 자연스러움을 우선해 설정 호칭을 참고하고, 필요하면 생략 또는 중립적 표현 허용
- `우선 적용`: USER를 명확히 부르는 자리에서는 설정한 호칭을 우선하며, 단순히 싸움/냉랭한 분위기라는 이유로 다른 호칭으로 바꾸지 않음
- `강하게 고정`: USER를 향한 일반 2인칭을 한국어에서 명시적으로 호칭해야 할 때 설정 호칭 외의 당신/그쪽/너/다른 관계 호칭으로 변경 금지
- 세 단계 모두 자연스러운 호칭 생략은 허용
- 원문에 직접 존재하는 애칭·명시 호칭·이름·직함·관계 호칭은 항상 고정 호칭보다 우선
- 개발자 모드 전용 테스트 기능이며 E→K TARGET CHARACTER 직접 대사에만 적용

### v0.4.57

- USER / CHAR 역할 별칭 해석을 대소문자 무관으로 보강
- `USER`, `User`, `user` 및 기타 대소문자 조합을 모두 현재 USER/페르소나와 같은 역할로 해석하도록 명시
- `TARGET CHARACTER`, `CHARACTER`, `CHAR/char` 계열도 대소문자 무관하게 현재 캐릭터와 같은 역할로 해석
- `{{user}}`, `{{char}}` 매크로 별칭은 기존처럼 유지
- 일반 모드에서도 항상 적용되며, 프롬프트 조건 해석에만 사용

### v0.4.56

- USER / `{{user}}` / 현재 페르소나 이름을 동일 인물로 해석하는 **프롬프트 역할 별칭 맵** 추가
- TARGET CHARACTER / `{{char}}` / 현재 캐릭터 이름도 동일 인물로 연결
- 캐릭터 대사 전용 프롬프트에 `{{user}}에게는 반말, {{user}} 외에는 존댓말`처럼 조건을 적었을 때 현재 SillyTavern USER/페르소나 이름을 기준으로 의미를 해석하도록 보강
- 별칭 맵은 프롬프트 조건 해석에만 사용하며, 원문 속 일반 단어를 강제 치환하거나 USER가 아닌 청자를 USER로 추측하지 않음
- 화자 분류, scoped 번역, 복구/검수 계열 프롬프트에도 동일한 USER/CHAR 역할 대응 정보를 유지
- 캐릭터/페르소나 시트 본문 전체를 보내는 방식이 아니라 현재 SillyTavern의 canonical 이름 메타데이터만 사용

### v0.4.55

- 개발자 모드 `관계 번역 실험실`의 USER 호칭 고정 규칙 보강
- 고정 호칭은 TARGET CHARACTER가 **현재 USER를 가리키는 것이 확실한 일반 2인칭**에만 적용
- 영어 `you`를 전부 고정 호칭으로 치환하지 않으며, 자연스러운 한국어에서는 호칭 생략 허용
- 원문의 애칭(term of endearment), 직접 호명, 직함, 관계 호칭, 이름이 있으면 **원문 표현이 고정 호칭보다 우선**
- 대상이 애매하거나 다른 인물/복수/인용문 속 `you`라면 고정 호칭 사용 금지
- 호칭 처리 우선순위: 원문 명시 호칭·애칭 > 설정한 USER 호칭 > 자연스러운 생략
- 개발자 모드 테스트 범위는 계속 E→K TARGET CHARACTER 직접 대사만 유지

### v0.4.54

- USER/NPC 대사 및 K→E 인풋에는 아직 적용하지 않음

## 기능

- AI 아웃풋을 항상 한국어로 자동번역
- 번역 요청 최대 출력 15,000토큰
- 연결 프로필 A/B/C를 설정하고 입력창 옆 `⇄ᴬ`·`⇄ᴮ`·`⇄ᶜ` 버튼으로 순환 전환
- `번역 실패 시 다른 프로필 자동 사용`을 켜면 현재 선택한 프로필의 일시적 오류에서 나머지 프로필을 차례로 임시 사용하되 수동 선택 상태는 유지
- 해당 설정을 끄면 현재 선택한 프로필만 자동 재시도하며 B/C로 자동 전환하지 않음
- 설정된 프로필이 모두 일시적으로 실패하면 기존 자동 재시도 주기를 적용
- 태그·매크로·URL·코드·HTML 인포블럭을 제외한 본문이 한국어 중심이면 API 호출 없이 자동 제외
- 한국어 본문을 판정할 때 태그 이름과 관계없이 완성된 여닫는 태그 블록의 내부 영문은 제외하여 불필요한 자동번역을 방지
- 태그 밖에 본문이 없으면 태그 내부 언어로 다시 판정하여 영어 인포블럭만 있는 출력도 정상 번역
- 영어 본문을 번역할 때는 HTML 태그·속성을 보존하면서 인포블럭 안의 자연어도 함께 번역
- 설정에서 `전송 시 인풋 자동번역`을 켜면 한국어 인풋을 영어로 번역한 뒤 전송
- 인풋 번역은 캐릭터 카드에서 명시된 성별·대명사만 로컬로 확인하고 정규화된 성별값 하나만 AI에 전달
- 인풋 자동번역 중 진행 토스트의 `×`를 누르면 번역 요청과 전송을 즉시 취소
- 인풋 번역 실패 시 한국어 원문 전송 및 뒤따르는 생성을 차단
- 서술과 대사에 모두 적용되는 `전체 번역 전역 프롬프트`
- 캐릭터·유저·NPC의 모든 직접 대사에 적용되는 `모든 대사 공통 프롬프트`
- 아웃풋 전체 문맥에서 화자를 판단해 현재 캐릭터의 직접 대사에만 추가 적용되는 `캐릭터 대사 전용 프롬프트`
- 캐릭터 전용 말투는 유저·NPC 대사와 캐릭터가 인용·회상·흉내 낸 문장에는 적용하지 않음
- 대사와 서술을 별도 번역 단위로 분리하여 대사 병기 설정이 문단 전체에 번지는 현상 방지
- 번역 금지어를 한 줄에 하나씩 등록
- 금지어가 발견되면 위반 문단만 다시 번역하고 정상 문단은 유지
- 번역문에 긴 외국어 원문이 그대로 남으면 해당 구간만 감지해 자동 재번역
- 이름·약어와 프롬프트로 요청한 대사 한영병기는 미번역으로 오인하지 않음
- 프롬프트 표현을 알아보지 못해도 `영문 대사 + (한국어 대사)` 결과 자체를 정상 병기로 인식
- 일부 구간의 미번역 의심이 복구되지 않아도 정상 번역된 나머지 결과는 적용
- 429·일시적 서버·네트워크 오류는 3 → 5 → 8 → 12 → 18초 간격으로 최대 5회 자동 재시도
- 서버가 `Retry-After` 대기 시간을 알려주면 그 시간을 우선 적용
- 서버 오류 재시도 횟수와 다음 요청까지의 대기 시간을 화면 아래 상태 배지로 표시
- 아래 재시도 상태 배지를 누르면 대기 중이거나 실행 중인 서버 오류 재시도를 즉시 취소
- 최종 번역 실패 알림도 화면 아래에 표시
- 확장 설정에서 프로필 A/B/C의 요청 수·성공률·평균 응답 시간·재시도·자동 대체 횟수를 로컬 통계로 확인하고 초기화
- 선택형 디버그 모드로 번역 내용과 인증 정보를 제외한 최근 진단 이벤트를 복사
- 번역문을 드래그한 뒤 선택 범위만 재번역
- 번역문에서 구간을 선택해 해당 번역 구간의 영어 원문을 API 재호출 없이 확인하고 복사
- 선택 부분 재번역 전에 이번 요청에만 쓰는 요구사항 입력
- 설정을 켜면 선택 부분의 의미를 유지한 서로 다른 번역 후보 3개를 한 번의 요청으로 생성
- 후보를 미리 비교해 하나를 선택한 경우에만 선택 영역을 교체하고, 취소하면 기존 번역 유지
- 번역문에서 이름을 선택해 원문의 대응 이름을 찾고 원하는 한국어 표기로 고정
- 고정한 이름은 캐릭터 카드의 베르바 확장 데이터에 저장되어 해당 캐릭터의 다른 채팅에서도 사용
- 이름 고정 시 현재 번역문의 같은 표기를 즉시 교체하고, 이후 번역에서는 원문 이름을 보호한 뒤 지정 표기로 복원
- 이름 고정 팝업에서 현재 채팅 전체의 이전 메시지와 다른 스와이프에 저장된 이름 표기도 자동으로 한꺼번에 변경
- 확장 설정의 기본 접힘 상태인 `이름 고정 관리`에서 캐릭터별 저장 이름을 확인하고 표기를 수정·삭제
- 각 번역 메시지의 복사 아이콘에서 번역문·영어 원문·원문과 번역문 중 원하는 형식으로 복사
- 입력창 옆 `↻` 버튼으로 가장 최근 AI 아웃풋 전체 재번역
- 자동번역에 실패한 스와이프도 입력창 옆 `↻`로 다시 번역 가능
- 전체 재번역 전에 대상 미리보기와 일회성 요구사항 입력
- 전체 재번역 창에서 영어 원문과 저장된 번역본을 API 재호출 없이 전환
- 채팅·메시지·스와이프가 바뀌면 늦게 도착한 이전 번역 결과를 폐기

- 번역했던 스와이프로 돌아오면 API를 다시 호출하지 않고 저장본을 즉시 복원
- 중간 스와이프를 삭제해 뒤쪽 번호가 당겨져도 원문을 기준으로 저장본 번호를 자동 보정
- 새 스와이프 생성 중 직전 원문을 새 원문으로 오인해 중복 번역하지 않음
- 새 스와이프 생성·번역이 끝날 때까지 화면에는 직전 번역본을 유지

## 스와이프 동작

각 스와이프의 번역본은 해당 스와이프가 원래 사용하는 `extra` 안에 따로 저장됩니다. 처음 보는 스와이프만 자동번역하며, 번역했던 스와이프로 돌아오면 원문이 같은지 확인한 뒤 저장본을 재사용합니다. 원문을 수정했거나 저장본이 없는 경우에만 다시 번역합니다. 선택 재번역과 전체 재번역 결과도 현재 스와이프에만 저장됩니다.

새 스와이프 생성을 시작해 번호만 먼저 바뀌고 새 원문이 아직 만들어지지 않은 동안에는 번역 요청을 보내지 않습니다. 이때 화면에는 직전 번역본을 그대로 유지합니다. 생성이 끝나 실제 새 원문이 들어오면 처음 한 번만 번역하고, 새 번역이 끝난 뒤 화면을 교체합니다. 스와이프 생성을 취소하면 직전 번역본으로 그대로 돌아갑니다.

## 고급 재번역 기능

별도 개발자 모드 없이 일반 설정에서 바로 사용할 수 있습니다. 번역문을 드래그하면 설정한 메뉴 구성에 따라 `구간 잠금`과 `묶음 추가`를 사용할 수 있습니다.

- 구간 잠금은 선택 영역과 맞닿은 베르바 번역 단위 전체를 다음 번역 1회 동안 보존합니다. 번역 성공 후에는 자동 해제되며, 실행 전에는 같은 구간을 다시 선택해 직접 해제할 수 있습니다.
- 묶음 추가를 여러 번 누르면 화면 아래에 선택 개수와 `한꺼번에 재번역` 버튼이 표시됩니다.
- 부분·묶음 재번역 창에서는 AI가 참고할 범위를 선택할 수 있으며 실제 교체 범위는 선택 구간으로 제한됩니다.
- 전체·부분·묶음 재번역 결과는 요청이 완료되면 현재 번역문에 바로 적용됩니다.
- 다음 AI 아웃풋이나 다른 스와이프로 이동하면 남아 있던 잠금·묶음 선택은 자동 초기화됩니다.
- `번역 미세 조정`에서 관계 온도와 서술·대사 현지화의 기본값을 설정할 수 있습니다. 현지화는 `원문 유지 · 약한 현지화 · 균형 · 자연스러운 한국어 · 네이티브 한국어` 5단계이며, 관계 온도는 대사에만 적용되고 서술과 대사는 서로 다른 현지화 수준을 선택할 수 있습니다.
- 전체·부분·묶음 재번역 창에서 기본값을 이번 요청에만 임시로 변경할 수 있으며 추가 API 호출은 발생하지 않습니다.

## 설치

1. 이 폴더를 SillyTavern의 `data/default-user/extensions/third-party/` 아래에 넣습니다.
2. SillyTavern을 새로고침합니다.
3. 확장 설정에서 연결 프로필 A를 선택하고, 빠른 전환이 필요하면 프로필 B와 C도 선택합니다.
4. 필요하면 인풋 자동번역, 전체 프롬프트, 모든 대사 공통 프롬프트, 캐릭터 대사 전용 프롬프트, 금지어를 설정합니다.

`display_text`를 사용하는 다른 번역 확장과 동시에 켜지 않는 것을 권장합니다.
