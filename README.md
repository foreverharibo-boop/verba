# 베르바

SillyTavern 1.18용 독립 자동번역 확장입니다.

현재 버전: **v0.3.39**

## 업데이트 내역

### v0.3.39

- `she`·`her`를 기계적으로 `그녀`·`그녀의`·`그녀에게`로 반복하던 보수적인 지시 수정
- 대명사가 현재 페르소나나 캐릭터를 명확하게 가리키면 전체 이름을 사용하거나 한국어 문맥에 맞게 주어·소유자를 생략
- 지칭 대상이 애매하거나 다른 NPC인 경우에는 페르소나 이름을 억지로 대입하지 않도록 제한
- 이름으로 번역할 때 마지막 음절을 조사로 오인하지 않고 전체 이름을 유지하는 v0.3.38 안전장치는 그대로 유지

### v0.3.38

- 현재 페르소나와 캐릭터의 한국어 이름을 분리할 수 없는 하나의 고유명사로 번역 프롬프트에 명시
- `혜담은`을 `혜담 + 조사 은`처럼 마지막 음절과 조사로 잘못 분석하지 않도록 이름 뒤에 조사가 붙는 규칙 강화
- AI가 `혜담의`, `혜담에게`처럼 이름의 마지막 음절을 누락해도 화면 적용 전에 `혜담은의`, `혜담은에게`로 자동 복구
- 이미 올바른 `혜담은`, `혜담은의` 표기는 중복 보정하지 않으며 이름과 비슷한 더 긴 일반 단어도 변경하지 않음
- 페르소나 이름은 화자 판별 문맥으로만 사용하며 `she`·`her` 같은 원문 대명사를 무조건 이름으로 치환하지 않음
- 전체·선택·후보·묶음 재번역에도 동일한 이름 분리 방지 보정 적용

### v0.3.37

- 개발자 모드에서 전체·선택·묶음 재번역을 적용한 직후 `되돌리기` 알약 표시
- 되돌린 직후에는 같은 위치에서 `다시 적용` 가능하며, 최근 재번역 기록은 메모리에 최대 5개까지 보관
- 최초 자동번역과 이름 고정·원문 보기 전환은 실행 취소 기록에서 제외
- 전체 번역 전역·모든 대사 공통·캐릭터 대사·이번 번역 요구사항 사이의 명확한 규칙 충돌만 감지하는 알림 추가
- 존댓말/반말, 한국어만/한영 병기, 직역/의역·현지화, 동일 원문 표기의 상이한 지정처럼 동시에 지킬 수 없는 규칙만 알림
- 충돌이 없으면 아무 알림도 표시하지 않으며, 충돌이 있어도 번역을 막지 않고 현재 규칙 우선순위에서 먼저 적용될 항목만 안내

### v0.3.36

- 개발자 모드의 별도 `서술·대사 개별 설정`과 `번역 보존 항목` 제거
- 기존 번역 미세 조정의 현지화 정도를 `서술 현지화`와 `대사 현지화`로 분리
- 서술과 대사는 각각 원문 유지·균형·한국어화 중 서로 다른 수준을 선택 가능
- 전체·부분·묶음 재번역 팝업에서도 서술·대사 현지화를 이번 요청에만 별도로 변경 가능
- 기존 단일 현지화 설정값은 업데이트 후 서술·대사 현지화 양쪽의 초기값으로 자동 승계
- 번역 규칙 우선순위에서 제거된 문체 분리·보존 항목을 정리하고 나머지 다섯 규칙만 유지

### v0.3.35

- 개발자 모드에 `서술·대사 개별 설정` 추가: 서술은 원문 충실·균형·문학적, 대사는 원문 충실·균형·자연스러운 구어체 중 선택
- 개발자 모드에 `번역 보존 항목` 추가: 고유명사, 호칭·직책, 숫자·날짜·단위, 시제·시점·화자, 문단·대사 서식을 각각 켜고 끌 수 있음
- 개발자 모드에 `번역 규칙 우선순위` 추가: 모바일에서도 사용하기 쉬운 위·아래 버튼으로 일회성 요구사항, 대사 프롬프트, 문체 분리, 전역 프롬프트, 미세 조정, 보존 규칙의 순서를 변경
- 세 기능은 추가 API 호출 없이 기존 전체·선택·묶음 재번역 및 교정 요청의 프롬프트에 반영
- 원문 정확성, 보호 태그·토큰, JSON 형식, 금지어 규칙은 사용자 우선순위와 관계없이 항상 최우선으로 유지

- 실패한 대체 프로필 요청은 `대체`에 포함하지 않도록 집계 기준 수정

- 프로필 성능 기록 중 평균 시간만 아웃풋 번역 시작부터 최종 적용 또는 실패 종료까지의 전체 시간으로 표시

- 번역 미세 조정을 끄면 관계 온도와 현지화 수준이 함께 비활성화되도록 변경

### v0.3.30

### v0.3.29

- 프로필 성능 화면을 실제 아웃풋 번역 시작부터 성공·실패 종료까지의 `평균 번역 시간`만 표시하도록 단순화

### v0.3.28

- 프로필 성능 기록에 아웃풋 번역 시작부터 최종 화면 적용 또는 실패까지의 전체 소요 시간 추가
- 전체 번역 시간에 요청 대기열·반복 용어 결정·본문 번역·금지어 및 미번역 보정·재시도 대기 시간을 모두 포함

- 취소되거나 새 스와이프·채팅 이동으로 폐기된 작업은 전체 번역 성능 통계에서 제외

- 출력 번역이 예기치 않게 결과 없이 종료되는 경우 실패 이유를 반드시 표시하는 안전장치 추가

### v0.3.27

- 개발자 모드에 `번역 미세 조정` 추가
- 관계 온도를 차가움·거리감·기본·가까움·친밀함의 5단계로 설정
- 관계 온도는 직접 대사의 어미·호칭·언어적 거리만 조절하고 서술에는 적용하지 않음
- 현지화 정도를 원문 유지·균형·한국어화의 3단계로 설정
- 현지화는 관용구·농담·일상 표현만 조절하고 인명·지명·통화·단위·설정·사실관계는 보존
- 개발자 모드의 기본값은 자동번역에 적용하고 전체·부분·묶음 재번역 창에서는 이번 요청에만 다른 값 선택 가능
- 기존 번역 요청 프롬프트에 미세 조정 규칙을 함께 전달하므로 별도의 API 호출을 추가하지 않음

### v0.3.26

- 개발자 모드 시험 기능의 진입·잠금·묶음·문맥 선택·초기화 흐름 전체 검수
- 개발자 모드를 끄거나 채팅을 이동한 뒤 임시 구간 잠금이 저장 데이터에 남아 다시 적용될 수 있던 문제 수정
- 재번역 요구사항 창을 연 채 채팅을 이동하면 대기 상태가 끝나지 않던 문제 수정
- 부분·묶음 재번역에서 띄어쓰기나 문장부호만 바꾼 결과도 기존 문장과 동일한 결과로 판정
- 묶음 재번역의 `메시지 전체` 문맥에서 같은 원문·번역문을 선택 구간 수만큼 중복 전송하던 구조 제거
- 전체 메시지 문맥은 한 번만 공유하고 각 선택에는 주변 문맥만 전달하여 긴 아웃풋의 요청 크기와 혼선을 축소

### v0.3.25

- 묶음 재번역 결과가 기존 선택 문장과 동일해도 성공으로 처리되던 문제 수정
- 기존 문장과 같은 결과가 포함되면 해당 구간을 명시하여 자동으로 한 번 더 재번역 요청
- 두 번째 결과도 동일하면 번역문을 덮어쓰거나 완료 알림을 띄우지 않고 명확한 실패로 처리
- 요구사항을 비워도 선택한 모든 구간의 표현을 실제로 바꾸도록 묶음 프롬프트 강화

- 여러 줄·중첩 태그가 포함된 선택에서 폭이 넓은 부모 요소 좌표가 섞여 화면 왼쪽으로 튀는 문제 수정

## 기능

- AI 아웃풋을 항상 한국어로 자동번역
- 번역 요청 최대 출력 15,000토큰
- 연결 프로필 A/B/C를 설정하고 입력창 옆 `⇄ᴬ`·`⇄ᴮ`·`⇄ᶜ` 버튼으로 순환 전환
- 현재 선택한 프로필 요청이 실패하면 나머지 프로필을 차례로 임시 사용하되 수동 선택 상태는 유지
- 설정된 프로필이 모두 일시적으로 실패하면 기존 자동 재시도 주기를 적용
- 태그·매크로·URL·코드·HTML 인포블럭을 제외한 본문이 한국어 중심이면 API 호출 없이 자동 제외
- 한국어 본문을 판정할 때 태그 이름과 관계없이 완성된 여닫는 태그 블록의 내부 영문은 제외하여 불필요한 자동번역을 방지
- 태그 밖에 본문이 없으면 태그 내부 언어로 다시 판정하여 영어 인포블럭만 있는 출력도 정상 번역
- 영어 본문을 번역할 때는 HTML 태그·속성을 보존하면서 인포블럭 안의 자연어도 함께 번역
- 설정에서 `전송 시 인풋 자동번역`을 켜면 한국어 인풋을 영어로 번역한 뒤 전송
- 인풋 번역은 캐릭터 카드에서 명시된 성별·대명사만 로컬로 확인하고 정규화된 성별값 하나만 AI에 전달
- 인풋 자동번역 중 진행 토스트의 `×`를 누르면 번역 요청과 전송을 즉시 취소
- 인풋 번역 실패 시 한국어 원문 전송 및 뒤따르는 생성을 차단
- 서술과 대사에 모두 적용되는 `전체 번역 전역 프롬프트`
- 캐릭터·유저·NPC의 모든 직접 대사에 적용되는 `모든 대사 공통 프롬프트`
- 아웃풋 전체 문맥에서 화자를 판단해 현재 캐릭터의 직접 대사에만 추가 적용되는 `캐릭터 대사 전용 프롬프트`
- 캐릭터 전용 말투는 유저·NPC 대사와 캐릭터가 인용·회상·흉내 낸 문장에는 적용하지 않음
- 대사와 서술을 별도 번역 단위로 분리하여 대사 병기 설정이 문단 전체에 번지는 현상 방지
- 번역 금지어를 한 줄에 하나씩 등록
- 금지어가 발견되면 위반 문단만 다시 번역하고 정상 문단은 유지
- 번역문에 긴 외국어 원문이 그대로 남으면 해당 구간만 감지해 자동 재번역
- 이름·약어와 프롬프트로 요청한 대사 한영병기는 미번역으로 오인하지 않음
- 프롬프트 표현을 알아보지 못해도 `영문 대사 + (한국어 대사)` 결과 자체를 정상 병기로 인식
- 일부 구간의 미번역 의심이 복구되지 않아도 정상 번역된 나머지 결과는 적용
- 429·일시적 서버·네트워크 오류는 3 → 5 → 8 → 12 → 18초 간격으로 최대 5회 자동 재시도
- 서버가 `Retry-After` 대기 시간을 알려주면 그 시간을 우선 적용
- 서버 오류 재시도 횟수와 다음 요청까지의 대기 시간을 화면 아래 상태 배지로 표시
- 아래 재시도 상태 배지를 누르면 대기 중이거나 실행 중인 서버 오류 재시도를 즉시 취소
- 최종 번역 실패 알림도 화면 아래에 표시
- 확장 설정에서 프로필 A/B/C의 요청 수·성공률·평균 응답 시간·재시도·자동 대체 횟수를 로컬 통계로 확인하고 초기화
- 선택형 디버그 모드로 번역 내용과 인증 정보를 제외한 최근 진단 이벤트를 복사
- 번역문을 드래그한 뒤 선택 범위만 재번역
- 번역문에서 구간을 선택해 해당 번역 구간의 영어 원문을 API 재호출 없이 확인하고 복사
- 선택 부분 재번역 전에 이번 요청에만 쓰는 요구사항 입력
- 설정을 켜면 선택 부분의 의미를 유지한 서로 다른 번역 후보 3개를 한 번의 요청으로 생성
- 후보를 미리 비교해 하나를 선택한 경우에만 선택 영역을 교체하고, 취소하면 기존 번역 유지
- 번역문에서 이름을 선택해 원문의 대응 이름을 찾고 원하는 한국어 표기로 고정
- 고정한 이름은 캐릭터 카드의 베르바 확장 데이터에 저장되어 해당 캐릭터의 다른 채팅에서도 사용
- 이름 고정 시 현재 번역문의 같은 표기를 즉시 교체하고, 이후 번역에서는 원문 이름을 보호한 뒤 지정 표기로 복원
- 이름 고정 팝업에서 현재 채팅 전체의 이전 메시지와 다른 스와이프에 저장된 이름 표기도 자동으로 한꺼번에 변경
- 확장 설정의 기본 접힘 상태인 `이름 고정 관리`에서 캐릭터별 저장 이름을 확인하고 표기를 수정·삭제
- 각 번역 메시지의 복사 아이콘에서 번역문·영어 원문·원문과 번역문 중 원하는 형식으로 복사
- 입력창 옆 `↻` 버튼으로 가장 최근 AI 아웃풋 전체 재번역
- 자동번역에 실패한 스와이프도 입력창 옆 `↻`로 다시 번역 가능
- 전체 재번역 전에 대상 미리보기와 일회성 요구사항 입력
- 전체 재번역 창에서 영어 원문과 저장된 번역본을 API 재호출 없이 전환
- 채팅·메시지·스와이프가 바뀌면 늦게 도착한 이전 번역 결과를 폐기
- 스와이프별 번역본을 SillyTavern의 기본 `swipe_info[].extra`에 저장
- 번역했던 스와이프로 돌아오면 API를 다시 호출하지 않고 저장본을 즉시 복원
- 중간 스와이프를 삭제해 뒤쪽 번호가 당겨져도 원문을 기준으로 저장본 번호를 자동 보정
- 새 스와이프 생성 중 직전 원문을 새 원문으로 오인해 중복 번역하지 않음
- 새 스와이프 생성·번역이 끝날 때까지 화면에는 직전 번역본을 유지

## 스와이프 동작

각 스와이프의 번역본은 해당 스와이프가 원래 사용하는 `extra` 안에 따로 저장됩니다. 처음 보는 스와이프만 자동번역하며, 번역했던 스와이프로 돌아오면 원문이 같은지 확인한 뒤 저장본을 재사용합니다. 원문을 수정했거나 저장본이 없는 경우에만 다시 번역합니다. 선택 재번역과 전체 재번역 결과도 현재 스와이프에만 저장됩니다.

새 스와이프 생성을 시작해 번호만 먼저 바뀌고 새 원문이 아직 만들어지지 않은 동안에는 번역 요청을 보내지 않습니다. 이때 화면에는 직전 번역본을 그대로 유지합니다. 생성이 끝나 실제 새 원문이 들어오면 처음 한 번만 번역하고, 새 번역이 끝난 뒤 화면을 교체합니다. 스와이프 생성을 취소하면 직전 번역본으로 그대로 돌아갑니다.

## 개발자 시험 기능

확장 설정의 `베르바` 제목줄을 5초 안에 7번 누르고 개발자 비밀번호를 입력하면 시험 기능이 활성화됩니다. 번역문을 드래그하면 기존 메뉴에 `구간 잠금`과 `묶음 추가`가 함께 표시됩니다.

- 구간 잠금은 선택 영역과 맞닿은 베르바 번역 단위 전체를 다음 번역 1회 동안 보존합니다. 번역 성공 후에는 자동 해제되며, 실행 전에는 같은 구간을 다시 선택해 직접 해제할 수 있습니다.
- 묶음 추가를 여러 번 누르면 화면 아래에 선택 개수와 `한꺼번에 재번역` 버튼이 표시됩니다.
- 부분·묶음 재번역 창에서는 AI가 참고할 범위를 선택할 수 있으며 실제 교체 범위는 선택 구간으로 제한됩니다.
- 전체·부분·묶음 재번역 결과는 요청이 완료되면 현재 번역문에 바로 적용됩니다.
- 다음 AI 아웃풋이나 다른 스와이프로 이동하면 남아 있던 잠금·묶음 선택은 자동 초기화됩니다.
- `번역 미세 조정`에서 관계 온도와 서술·대사 현지화의 기본값을 설정할 수 있습니다. 관계 온도는 대사에만 적용되며, 서술과 대사의 현지화 수준은 각각 따로 선택할 수 있습니다.
- 전체·부분·묶음 재번역 창에서 기본값을 이번 요청에만 임시로 변경할 수 있으며 추가 API 호출은 발생하지 않습니다.

## 설치

1. 이 폴더를 SillyTavern의 `data/default-user/extensions/third-party/` 아래에 넣습니다.
2. SillyTavern을 새로고침합니다.
3. 확장 설정에서 연결 프로필 A를 선택하고, 빠른 전환이 필요하면 프로필 B와 C도 선택합니다.
4. 필요하면 인풋 자동번역, 전체 프롬프트, 모든 대사 공통 프롬프트, 캐릭터 대사 전용 프롬프트, 금지어를 설정합니다.

`display_text`를 사용하는 다른 번역 확장과 동시에 켜지 않는 것을 권장합니다.
