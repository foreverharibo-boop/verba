# 베르바

SillyTavern 1.18용 독립 자동번역 확장입니다.

현재 버전: **v0.1.11**

## 기능

- AI 아웃풋을 항상 한국어로 자동번역
- 번역 요청 최대 출력 15,000토큰
- 태그·매크로·URL·코드 등을 제외한 본문이 한국어 중심이면 API 호출 없이 자동 제외
- 설정에서 `전송 시 인풋 자동번역`을 켜면 한국어 인풋을 영어로 번역한 뒤 전송
- 인풋 번역 실패 시 한국어 원문 전송 및 뒤따르는 생성을 차단
- 서술과 대사에 모두 적용되는 `전체 번역 전역 프롬프트`
- 캐릭터·유저·NPC의 모든 직접 대사에 적용되는 `모든 대사 공통 프롬프트`
- 아웃풋 전체 문맥에서 화자를 판단해 현재 캐릭터의 직접 대사에만 추가 적용되는 `캐릭터 대사 전용 프롬프트`
- 캐릭터 전용 말투는 유저·NPC 대사와 캐릭터가 인용·회상·흉내 낸 문장에는 적용하지 않음
- 대사와 서술을 별도 번역 단위로 분리하여 대사 병기 설정이 문단 전체에 번지는 현상 방지
- 번역 금지어를 한 줄에 하나씩 등록
- 금지어가 발견되면 위반 문단만 다시 번역하고 정상 문단은 유지
- 번역문에 긴 외국어 원문이 그대로 남으면 해당 구간만 감지해 자동 재번역
- 이름·약어와 프롬프트로 요청한 대사 한영병기는 미번역으로 오인하지 않음
- 프롬프트 표현을 알아보지 못해도 `영문 대사 + (한국어 대사)` 결과 자체를 정상 병기로 인식
- 일부 구간의 미번역 의심이 복구되지 않아도 정상 번역된 나머지 결과는 적용
- 429·일시적 서버·네트워크 오류는 3 → 5 → 8 → 12 → 18초 간격으로 최대 5회 자동 재시도
- 서버가 `Retry-After` 대기 시간을 알려주면 그 시간을 우선 적용
- 서버 오류 재시도 횟수와 다음 요청까지의 대기 시간을 화면 아래 상태 배지로 표시
- 아래 재시도 상태 배지를 누르면 대기 중이거나 실행 중인 서버 오류 재시도를 즉시 취소
- 최종 번역 실패 알림도 화면 아래에 표시
- 번역문을 드래그한 뒤 선택 범위만 재번역
- 선택 부분 재번역 전에 이번 요청에만 쓰는 요구사항 입력
- 입력창 옆 `↻` 버튼으로 가장 최근 AI 아웃풋 전체 재번역
- 자동번역에 실패한 스와이프도 입력창 옆 `↻`로 다시 번역 가능
- 전체 재번역 전에 대상 미리보기와 일회성 요구사항 입력
- 채팅·메시지·스와이프가 바뀌면 늦게 도착한 이전 번역 결과를 폐기
- 스와이프별 번역본을 SillyTavern의 기본 `swipe_info[].extra`에 저장
- 번역했던 스와이프로 돌아오면 API를 다시 호출하지 않고 저장본을 즉시 복원
- 새 스와이프 생성 중 직전 원문을 새 원문으로 오인해 중복 번역하지 않음

## 스와이프 동작

각 스와이프의 번역본은 해당 스와이프가 원래 사용하는 `extra` 안에 따로 저장됩니다. 처음 보는 스와이프만 자동번역하며, 번역했던 스와이프로 돌아오면 원문이 같은지 확인한 뒤 저장본을 재사용합니다. 원문을 수정했거나 저장본이 없는 경우에만 다시 번역합니다. 선택 재번역과 전체 재번역 결과도 현재 스와이프에만 저장됩니다.

새 스와이프 생성을 시작해 번호만 먼저 바뀌고 새 원문이 아직 만들어지지 않은 동안에는 번역 요청을 보내지 않습니다. 생성이 끝나 실제 새 원문이 들어온 뒤에만 처음 한 번 번역합니다.

## 설치

1. 이 폴더를 SillyTavern의 `data/default-user/extensions/third-party/` 아래에 넣습니다.
2. SillyTavern을 새로고침합니다.
3. 확장 설정에서 번역기 전용 연결 프로필을 선택합니다.
4. 필요하면 인풋 자동번역, 전체 프롬프트, 모든 대사 공통 프롬프트, 캐릭터 대사 전용 프롬프트, 금지어를 설정합니다.

`display_text`를 사용하는 다른 번역 확장과 동시에 켜지 않는 것을 권장합니다.
