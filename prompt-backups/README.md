- 기준 버전: 0.6.118
- 원본 커밋: `69b43ce64f4e2ffce37d2af23eea088766bf0ae5`
- 원본: `deepseek-korean.js`의 `DEEPSEEK_KOREAN_PROMPT`
- 백업: [deepseek-before-dedup-v0.6.118.txt](deepseek-before-dedup-v0.6.118.txt)

- 문구를 변경하거나 설명을 덧붙이지 않은 원문 그대로이며, 후검수 프롬프트는 별도입니다. 이번 중복 정리에서 후검수는 변경하지 않았습니다.

## 복구

사용자가 중복 정리 전으로 복구를 요청하면 이 파일의 내용으로 내장 `DEEPSEEK_KOREAN_PROMPT`만 복원합니다. 전체 저장소를 옛 커밋으로 되돌려 이후의 UI·기능 수정을 잃지 않도록 합니다. 현재 코드의 템플릿 문자열에 안전하게 넣고, 확장 버전과 서버 엔진을 일관되게 갱신하여 새 버전으로 배포합니다.

사용자가 직접 시험하려면 커스텀 번역기의 ‘딥식 플래시 전용’ 칸에 백업 내용 전체를 붙여 넣고 커스텀 번역기를 활성화할 수도 있습니다. 이 경우 저장한 커스텀 문구는 이후 업데이트로 덮어쓰지 않습니다. 현재 내장 지침으로 돌아오려면 해당 칸의 ‘기본값’을 누릅니다. 백업을 열거나 보관하는 것만으로는 적용되지 않습니다.

## 0.6.122 간결한 지침 시험의 복구 기준

0.6.121에서 사용하던 기본 지침은 위 0.6.118 텍스트 백업과 바이트 단위로 동일함을 확인했습니다. 0.6.122의 여섯 항목 시험판을 되돌릴 때도 같은 백업으로 최초 번역용 기본 지침만 복구합니다. 백업은 계속 실행·로드되지 않으며, 긴르바와 후검수 및 편집칸 위치는 복구 대상이 아닙니다.
